# FactFormer

Official implementation of Scalable Transformer for PDE surrogate modeling [(paper)](https://arxiv.org/abs/2305.17560) .
The implementation of FactFormer have been taked from the original repo [FactFormer](https://github.com/BaratiLab/FactFormer).

We have added an adapter to make make the code accesible and reusable.
