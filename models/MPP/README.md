# Multiple Physics Pretraining (MPP)

Repository for experiment code for our paper [Multiple Physics Pretraining (MPP)](https://openreview.net/forum?id=DKSI3bULiZ). 
The implementation of MPP have been taked from the original repo [multiple_physics_pretraining](https://github.com/PolymathicAI/multiple_physics_pretraining)

We have added an adapter to make make the code accesible and reusable.
